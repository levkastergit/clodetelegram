# clodetelegram

Мини-приложение Telegram для общения с Claude. Сервер работает на вашем
компьютере, использует [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview)
и вашу подписку Claude (Pro/Max) через авторизацию Claude Code — отдельный
API-ключ не нужен.

Клод работает как полноценный агент: читает и редактирует файлы в рабочей папке,
выполняет команды (с вашего подтверждения кнопкой) и отвечает в чат
мини-приложения. Бот в Telegram служит лаунчером: открывает приложение кнопкой.

## Требования

- Windows / macOS / Linux, Node.js 18.14+
- Выполненный вход в Claude Code с подпиской (файл `~/.claude/.credentials.json` существует)
- Telegram-аккаунт
- Туннель до локального сервера (например, [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) или ngrok) —
  Telegram открывает мини-приложения только по HTTPS

## Установка

1. Клонируйте репозиторий и установите зависимости:

   ```
   git clone https://github.com/levkastergit/clodetelegram.git
   cd clodetelegram
   npm install
   ```

2. Создайте бота в Telegram: напишите [@BotFather](https://t.me/BotFather) команду
   `/newbot`, задайте имя и получите токен.

3. Узнайте свой числовой Telegram ID: напишите боту [@userinfobot](https://t.me/userinfobot).

4. Скопируйте `.env.example` в `.env` и заполните:

   ```
   TELEGRAM_BOT_TOKEN=токен от BotFather
   ALLOWED_USER_IDS=ваши числовые ID через запятую
   PROJECTS_DIR=корневая папка проектов (внутри — папки проектов и _chat)
   ```

5. Поднимите туннель до локального сервера и впишите выданный HTTPS-адрес
   в `WEBAPP_URL` в `.env`:

   ```
   cloudflared tunnel --url http://localhost:3000
   ```

   У бесплатного туннеля cloudflared адрес меняется при каждом запуске —
   после перезапуска туннеля обновите `WEBAPP_URL` и перезапустите бота
   (кнопка меню обновится автоматически, BotFather не нужен).

6. Запустите:

   ```
   npm run dev
   ```

   Для продакшена: `npm run build`, затем `npm start`.

## Использование

Откройте мини-приложение: кнопка меню слева от поля ввода в чате с ботом
(или кнопка «🚀 Открыть Claude» в ответ на любое сообщение).

Интерфейс сделан в духе панели Claude Code: слева сайдбар, справа чат.

- **Менеджер сессий** — «+ Новая сессия»: чат без проекта, новый проект
  или проект из списка (репозитории GitHub-аккаунта; несклонированные
  клонируются при выборе), с продолжением любого прошлого диалога.
  Сессий может быть несколько, до 3 задач выполняются параллельно —
  между сессиями можно свободно переключаться, пока Клод работает.
- **Лимиты** — прогресс-бары использования подписки в сайдбаре
  (как `/usage` в Claude Code; экспериментальный метод SDK). Только владельцу.
- **⚙ Настройки** — авто-режим (действия без подтверждений) и выбор модели.
- **+** — прикрепить файлы: они сохраняются в `_incoming` рабочей папки,
  и Клод получает их пути.
- **Стоп** — прервать задачу текущей сессии.

Когда Клод просит разрешение на команду или задаёт вопрос с вариантами —
в чате появляется карточка с кнопками. На вопрос можно ответить и текстом.

## Гостевой доступ

Второму аккаунту можно дать ограниченный доступ (`GUEST_USERNAMES` /
`GUEST_USER_IDS` в `.env`). Гость:

- видит только один проект (`GUEST_PROJECT`, папка `GUEST_PROJECT_DIR`);
- видит только диалоги, начатые им самим;
- не может выполнять Bash и запускать субагентов;
- работает с файлами только внутри папки проекта (проверяется на сервере);
- не видит лимиты подписки и другие личные данные владельца.

## Безопасность

- Каждый запрос к API проверяется по подписи `initData` мини-приложения
  (HMAC с токеном бота, по алгоритму из документации Telegram); доступ
  получают только `ALLOWED_USER_IDS` (владелец) и гостевые аккаунты.
- Чтение файлов, поиск и правки внутри рабочей папки разрешены автоматически
  (режим `acceptEdits`).
- Выполнение произвольных команд (Bash) требует подтверждения кнопкой.
  Без ответа в течение 10 минут — отказ.
- Состояние (выбранный проект и привязка диалогов) хранится локально
  (`state.json`, в git не попадает).

## Важно про подписку

Документация Anthropic запрещает предоставлять вход через claude.ai или лимиты
подписки **третьим лицам** в продуктах на базе Agent SDK. Этот инструмент
рассчитан на личное использование под вашим собственным логином — не раздавайте
доступ к нему посторонним; для публичного сервиса нужен API-ключ.

## Как это устроено

- `src/bot.ts` — точка входа: тонкий бот-лаунчер на [grammY](https://grammy.dev)
  (кнопка открытия мини-приложения) и запуск веб-сервера.
- `src/webapp.ts` — HTTP-сервер (express): проверка `initData`, REST API
  и поток событий (SSE) для интерфейса.
- `src/claude.ts` — запуск «хода» Клода через `query()` из
  `@anthropic-ai/claude-agent-sdk`; колбэк `canUseTool` превращает запросы
  разрешений в карточки с кнопками; здесь же ограничения гостя.
- `src/state.ts` — состояние пользователей, список проектов и прошлых сессий,
  чтение истории диалога из `~/.claude/projects`.
- `public/` — интерфейс мини-приложения (ванильный JS + Telegram WebApp SDK).
- Каждый пользователь привязан к сессии Клода (`resume: sessionId`), поэтому
  диалог сохраняет контекст между сообщениями.

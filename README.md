# clodetelegram

Telegram-бот для общения с Claude. Бот работает на вашем компьютере, использует
[Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) и вашу
подписку Claude (Pro/Max) через авторизацию Claude Code — отдельный API-ключ не нужен.

Клод работает как полноценный агент: читает и редактирует файлы в рабочей папке,
выполняет команды (с вашего подтверждения кнопкой в Telegram) и отвечает в чат.

## Требования

- Windows / macOS / Linux, Node.js 18.14+
- Выполненный вход в Claude Code с подпиской (файл `~/.claude/.credentials.json` существует)
- Telegram-аккаунт

## Установка

1. Клонируйте репозиторий и установите зависимости:

   ```
   git clone https://github.com/levkastergit/clodetelegram.git
   cd clodetelegram
   npm install
   ```

2. Создайте бота в Telegram: напишите [@BotFather](https://t.me/BotFather) команду
   `/newbot`, задайте имя и получите токен.

3. Узнайте свой числовой Telegram ID: напишите боту [@userinfobot](https://t.me/userinfobot).

4. Скопируйте `.env.example` в `.env` и заполните:

   ```
   TELEGRAM_BOT_TOKEN=токен от BotFather
   ALLOWED_USER_ID=ваш числовой ID
   WORKING_DIR=папка, где агент будет работать с файлами
   ```

5. Запустите:

   ```
   npm run dev
   ```

   Для продакшена: `npm run build`, затем `npm start`.

## Использование

Напишите боту любую задачу — он передаст её Клоду и пришлёт ответ.

| Команда | Действие |
|---|---|
| `/new` | Начать новый диалог (сбросить контекст) |
| `/stop` | Прервать текущую задачу |
| `/status` | Показать, выполняется ли что-то сейчас |

## Безопасность

- Бот отвечает **только** пользователю с `ALLOWED_USER_ID`; все остальные игнорируются.
- Чтение файлов, поиск и правки внутри `WORKING_DIR` разрешены автоматически
  (режим `acceptEdits`).
- Выполнение произвольных команд (Bash) требует подтверждения кнопкой
  «✅ Разрешить / ❌ Отклонить» в Telegram. Без ответа в течение 10 минут — отказ.
- Контекст диалога хранится локально (`sessions.json`, в git не попадает).

## Важно про подписку

Документация Anthropic запрещает предоставлять вход через claude.ai или лимиты
подписки **третьим лицам** в продуктах на базе Agent SDK. Этот бот рассчитан на
личное использование под вашим собственным логином — не раздавайте доступ к нему
другим людям; для публичного сервиса нужен API-ключ.

## Как это устроено

- `src/bot.ts` — весь бот: [grammY](https://grammy.dev) принимает сообщения
  Telegram, `query()` из `@anthropic-ai/claude-agent-sdk` запускает агента.
- Каждый чат привязан к сессии Клода (`resume: sessionId`), поэтому диалог
  сохраняет контекст между сообщениями.
- Колбэк `canUseTool` превращает запросы разрешений агента в инлайн-кнопки Telegram.
